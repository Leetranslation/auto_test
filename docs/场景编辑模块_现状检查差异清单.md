# 场景编辑模块 — 现状检查差异清单

> 依据《场景编辑模块修正需求说明书 V2.1》，第一步现状检查输出。

## 一、当前实现概览

- 前端：`frontend/src/views/scene/index.vue`（Vue Flow 四栏：左节点组件库 / 中画布 / 右节点属性 / 底部日志+变量）
- 节点结构：`graphJson = { nodes:[{nodeKey,nodeType,nodeName,config}], edges:[{source,target,condition}] }`
- 后端：`/api/scene/version/save` 存 graphJson；`ExecutionService` 已按 edges 做 DAG 拓扑执行 + 条件分支
- Python Runner：`runner/ui_runner.py`（Playwright）

## 二、差异清单

| # | 需求要求 | 当前状态 | 差异 |
|---|---|---|---|
| G1 | 左侧 = API 列表（API列表/未使用/已使用 + 添加API + 分页 + 使用状态） | 左侧 = 节点组件库 | 不符 |
| G2 | 右侧 = 4 标签管理区（基础信息/上下文管理/脚本管理/流程管理） | 右侧 = 节点属性 JSON 配置 | 不符 |
| G3 | 主页面无底部日志+变量面板 | 有底部日志+变量面板 | 多余 |
| G4 | 画布节点显示业务操作名称 | 节点显示技术类型标签 | 需改 |
| G5 | 节点与 API 资产真实 ID 关联 | 节点 config 无 api_definition_id | 缺失 |
| G6 | 节点支持 Python 脚本绑定（独立存储） | 无脚本字段 | 缺失 |
| G7 | 第二层节点详细编辑页 | 无 | 缺失 |
| G8 | 真实代码编辑器（Python 高亮/行号/缩进） | textarea | 缺失 |
| G9 | 脚本保存/加载后端接口 | 无 | 缺失 |
| G10 | 接口历史数据查询接口（脱敏） | 无 | 缺失 |
| G11 | 脚本调试接口（复用 Python Runner） | 无 | 缺失 |
| G12 | SCRIPT 节点执行语义 | 引擎仅执行 7 类节点 | 缺失 |
| G13 | 数据库最小迁移（节点脚本/API关联） | scene_node 表未映射，无 script 字段 | 需迁移 |

## 三、结论

当前页面为「通用拖拽式流程编辑器」，不符合确认的「第一张图（场景主页面）+ 第二张图（节点详细编辑页）」两层交互模式，需按说明书第二~四步实施修改。
